# Biblioteca de imágenes

Imágenes reutilizables entre historias, para el modo **elegir** (`guias/imagenes.md`).

- `imagenes/indice.json`: id, archivo, etiquetas, descripción, fuente y licencia de cada imagen.
- Añadir: `bin/mesa imagen biblioteca-agregar <ruta> --etiquetas a,b,c --descripcion "..." --fuente "..." --licencia "..."`.
- Buscar: `bin/mesa imagen buscar "muelle niebla"`.

Solo imágenes que se puedan usar: propias, de dominio público o con licencia libre anotada.
